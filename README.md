# Installation steps

To install addtwonumbers mcp server, run the following command:

Macos:
run "which uvx" grab package tool path

```json
  "mcpServers": {
    "addtwonumbers": {
      "command": "path/uvx",
      "args": [
        "--from",
        "git+https://github.com/svefa/mcpserverexample.git",
	"mcp-server"
      ]
    }
  }
```

Edit config: Claude/Settings/Developer
